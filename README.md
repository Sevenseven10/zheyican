# 吃过什么 / V0.1

Expo + React Native 的本地食物照片日记。记录保存在 SQLite，原始照片副本保存在 App 沙盒目录 `meal-photos/`。

## 真机验收

1. 在本机运行 `npm start`。
2. 使用同一网络下的 Expo Go 扫描终端二维码。
3. 点击底部 `＋`，拍照或从相册选择 1–6 张照片。
4. 输入吃了什么、选择餐次后保存；在 Today 和 History 确认记录。
5. 退出并重新打开 App，确认记录和照片仍存在。
